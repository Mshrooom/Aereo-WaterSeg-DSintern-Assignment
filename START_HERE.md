# Start here

1. Open `notebooks/aereo_sam_production_pipeline.ipynb` in a fresh Kaggle GPU notebook.
2. Upload this repository ZIP as a Kaggle dataset or clone the repository to `/kaggle/working/aereo-water-sam`.
3. Attach the `Satellite Images of Water Bodies` Kaggle dataset.
4. Run the notebook from top to bottom. The default run uses the complete train, validation, and test splits.
5. Download `/kaggle/working/aereo-water-sam-results.zip` after evaluation.
6. Use `MIGRATION_FROM_CURRENT_NOTEBOOK.md` to explain the engineering improvement during the interview.
7. Populate the report and presentation templates only with metrics produced by the complete run.
